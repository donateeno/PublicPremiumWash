# PublicPremiumWash

ตารางซื้อซิงค์แถมก๊อกน้ำ / ลดราคาก๊อกน้ำ — EVE

หน้าเว็บหน้าเดียว (`index.html`) แสดงตารางโปรโมชั่นซื้อซิงค์ล้างจานแล้วแถมหรือลดราคาก๊อกน้ำ พร้อมเงื่อนไขของโปรโมชั่น

## ข้อมูล

ดึงสดจาก Google Sheet ที่เผยแพร่เป็น CSV ทุกครั้งที่เปิดหน้า ทุก 5 นาที และเมื่อกลับมาที่แท็บ มีปุ่ม **รีเฟรช** สำหรับดึงทันที

ถ้าดึงไม่สำเร็จ หน้าเว็บจะใช้ snapshot ที่ฝังไว้ในไฟล์แทน และแถบสถานะจะขึ้นไฟแดงพร้อมสาเหตุ

เปลี่ยนแหล่งข้อมูลได้ที่ค่าคงที่ `PUB_CSV` ใน `index.html` หรือกดปุ่ม **ตั้งค่า** บนหน้าเว็บเพื่อใส่ลิงก์ CSV อื่น (เก็บใน localStorage ของเครื่องที่เปิด)

โครงสร้างที่ตัวอ่านคาดหวังจากชีท: แถวหัวตารางขึ้นต้นด้วย `EAN13` ในคอลัมน์แรก, ชื่อรุ่นก๊อกน้ำเริ่มที่คอลัมน์ที่ 6, แถวถัดไปเป็นราคาขายปกติ, แถวสินค้าขึ้นต้นด้วย EAN 13 หลัก และเงื่อนไขอยู่ใต้เซลล์ที่เขียนว่า `เงื่อนไข`

## สถานะในตาราง

| ค่าในชีท | แสดงผล |
|---|---|
| `YES` | ฟรี (แถมฟรี) |
| `ลด 35%` | ซื้อในราคาลด 35% |
| `SET` หรือ `SET: 10,990` | ขายเป็นชุด พร้อมราคาชุดถ้ามี |
| `NO` หรือว่าง | ไม่ร่วมรายการ |

## การใช้งานหน้าเว็บ

ค้นหารุ่นซิงค์หรือ EAN13, กรองตามรุ่นก๊อกน้ำ (คลิกที่หัวคอลัมน์ได้), กรองตามสถานะ, ขยายตารางเต็มจอ

ตารางตรึงคอลัมน์ซ้ายและหัวตารางไว้ บนมือถือเมื่อเลือกก๊อกน้ำหนึ่งรุ่นจะสลับเป็นมุมมองการ์ด

## เทคนิค

ไฟล์เดียว ไม่มี build step ไม่มี dependency นอกจากฟอนต์ Noto Sans Thai จาก Google Fonts — เปิดจากไฟล์ตรง ๆ ก็ได้ สี ตัวอักษร และระยะห่างอ้างอิง EVE CI 2024
